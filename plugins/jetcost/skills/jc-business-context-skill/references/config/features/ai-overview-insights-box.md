# AI-OVERVIEW-INSIGHTS-BOX

Named "Ai Overview Insight Box" in the backoffice. The web site no
longer reads this flag: changing it has no effect. It used to show,
above the flight results of the Jetcost site, a box presented as an AI
overview: a summary of the route made of fixed translated sentences
filled with its figures (cheapest price of the last 15 days, average
flight time, cheapest month, first and last flight times, flights per
week) and a few highlighted itineraries, such as the cheapest, the
cheapest direct and the fastest. The box has been removed from the
site.

## Configs

### ENABLED
Boolean, default `0`. No longer has any effect: it switched the box on.
