# MAL-FLIGHTS-CHECKBOXES

Controls whether the **checkbox** placement — a MAL Media unit, see
[core/commercials/integration-types.md](/core/commercials/integration-types.md) —
is shown on the flights product. One sibling feature per product:
`MAL-FLIGHTS-CHECKBOXES`, `MAL-CARS-CHECKBOXES`, `MAL-HOTELS-CHECKBOXES`
(deprecated).

## Configs

### ENABLED
Whether the checkbox placement is enabled.

### MAX-PARTNERS
The maximum number of partners the checkbox placement is opened for —
that is, how many checkboxes the user can potentially tick.
