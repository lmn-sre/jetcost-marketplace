# CUG — Closed User Group

## Overview

A W2A mechanism that surfaces on web offers whose
price is available only on app. Incentivises users
to switch platforms by showing them exclusive
pricing they can only get in the app.

## How It Works

On web, certain flight offers keep their price,
labelled as an app price with the full price
struck through and the discount shown, while the
partner name is blurred; clicking the offer opens
an overlay that sends the user to the app. The
same offer is fully visible and bookable on the
app. This creates a pricing incentive for the user
to switch to app.

## Revenue Implications

CUG is a softer W2A intervention than the blocking
element: it does not interrupt the user flow but
creates a pull incentive toward the app. Users
who switch are self-selected as price-sensitive
and motivated, which tends to produce strong
downstream conversion.
