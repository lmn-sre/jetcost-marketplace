# Media

What the media team runs: **display** advertising — banners and search
text ads, structurally independent of the click-monetisation funnel
that Core revenue depends on — and the data business. See
[core/business/revenue-streams.md](/core/business/revenue-streams.md)
for how these streams are accounted for alongside Core.

The folder follows ownership, not accounting. Data monetisation sits
here because the media team runs it, but it is a revenue stream of its
own, outside both Core and Media: it has nothing to do with
advertising, so never add it to Media revenue.

MAL is **not** here, even though MAL Media revenue is accounted as
Media: it is a commercial tool for managing partner relationships and
integrations, and it lives in
[core/commercials/mal/](/core/commercials/mal/index.md).

## Files

- [gam.md](/core/media/gam.md) - Google Ad Manager: banners on web and app, paid per impression, open auction and direct deals
- [afs.md](/core/media/afs.md) - AdSense for Search: query-matched text ads on web only, paid per click, gated against Core cannibalisation
- [metrics.md](/core/media/metrics.md) - media metrics: gross vs net revenue, GAM inventory metrics (requests, fill rate, eCPM, viewability), AFS metrics (queries, coverage, CTR, CPC, RPM)
- [data-monetization.md](/core/media/data-monetization.md) - emerging stream from selling anonymised user data to partners; run by the media team, accounted outside Media
